Project 2: Dice Game
This is the second project in this repo.
In this project, I have implemented a simple Dice Game using slightly more advanced React concepts, including:

Component reusability and structure
State management with useState and useEffect
Styled Components for custom styling
Event handling and conditional rendering

This project will help beginners and intermediate learners practice building interactive UI elements in React, understand dynamic state updates, and explore styling React components using Styled Components.
